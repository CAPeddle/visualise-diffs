Purpose: D-04 keeps volatile metadata apart from the canonical outputs by adding a sixth output file, `run.meta.json` (plan 02-11). Without this constant, that one new file would need about ten test edits (RESEARCH Pitfall 6), and every later change to the output set would need them again.

- 02-01 (this plan): the shared output-file constant.
- 02-11: `RunMeta` and `run.meta.json`, added end to end through pipeline, writers and CLI; `report.html` reads its commit ids from `RunMeta`, and in the same commit the diff record drops its two commit fields.
- 02-03: the model records become `vdiff-model/v1`, which has no commit or tool-version field, so those fields leave the model there.
- 02-12: the diff records become `vdiff-diff/v1`, and the separation test (same trees under different commits give identical canonical files) proves the split.
