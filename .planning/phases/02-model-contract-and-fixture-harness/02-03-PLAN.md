## Contract tables (authoritative; plan 02-05 transcribes them into schema)

Rules for every table:
- Declaration order of the record's positional parameters is the JSON key order (snake_case via `JsonNamingPolicy.SnakeCaseLower`).
- `?` marks a nullable property. It is omitted from JSON when null and is not in the schema's `required` list. Every other property is required, and lists are always written, even when empty.
- `code` means a string matching `^[a-z][a-z0-9-]*$`.
- `lang` is the enum `cpp | csharp | cpp-cli`.
- `access` is the enum `public | protected | private | internal | protected-internal | private-protected | none`.

Presence rules, which the schema descriptions document and tests enforce (draft-07 subset, no `if/then`, D-15):
- A `MemberDiff` `*_before` field is present exactly when the member exists on the base side, and `*_after` exactly when it exists on the head side. This applies to access, signature and modifiers alike.
- `TypeDiff.BaseFile` is present when the base side exists, and `HeadFile` when the head side exists.
- `RenamedFrom` and `Rename` are present only for state `renamed`. `RenamedFromKey` is present only for member state `renamed`.
- `PackageDiff.OldVersion` is present for `updated` and `removed`, and `NewVersion` for `updated` and `added`.
- Unchanged types and unchanged edges are counted, never listed.
- `ScoreMilli` is `500 * shared / total` (integer division, rounded down; 0 when total is 0) + 200 for same file or git rename pair + 200 for same namespace + 100 for same base set. The R-14 threshold is 600.

**Canonical order (one module, `Canonical.cs`).** Every comparer is total: on a full tie it ends with an ordinal compare of the element serialised with the shared options.

| Collection | Order (all `StringComparer.Ordinal`) |
|-----------|-------|
| `extraction.languages` | language |
| `macros_blanked`, `modifiers`, `bases`, `duplicates`, diff `warnings`, `bases.added`, `bases.removed`, `modifiers_before`, `modifiers_after` | value |
| `files` | path, language |
| `unmodelled` | path, reason |
| model `types` | language, id, file, span.start_byte |
| model `members` | key, span.start_byte, span.end_byte |
| model and diff `edges` | kind, from.language, from.id, to_name, to.language (absent first), to.id, via (absent first), then state for diff edges |
| diff `packages` | name, state |
| diff `types` | language, id |
| diff `members` | key |
| run meta `extractors` / `tools` | name / tool |
