  <action>
Create `scripts/trace-run.ps1`, written to run under both Windows PowerShell 5.1 and PowerShell 7 (no `??`, no ternary, no `?.`). Parameters: mandatory `-Repo`, `-Base`, `-Head`, `-Out`; optional `-Blank` and `-Include` (string arrays, passed through as repeated `--blank` and `--include`), `-VdiffDll` (default `src/Vdiff.Cli/bin/Release/net10.0/vdiff.dll` under the repository root found from `$PSScriptRoot`), `-LogPath` (a file outside both repositories that receives vdiff's output for private diagnosis; without it output is discarded), `-SkipMermaid`.
Behaviour (D-01, D-02, D-09; T-01-23 to T-01-26):
1. Wrap the whole script in a try/catch; any exception prints the failure block with reason `script-error` and exits 1. Nothing but the six lines below is ever written to stdout, and no value that came from a parameter, an exception message or vdiff's output is ever echoed.
2. Validate: `-Base` and `-Head` are 7 to 64 hexadecimal characters; `-Repo` is an existing directory that `git rev-parse --git-dir` accepts; otherwise reason `bad-arguments`. Resolve the full `-Out` path and refuse it (reason `out-not-outside`) when it lies inside the analysed repository's work tree or git directory, or inside this repository's root, comparing on directory boundaries and case-insensitively on Windows.
3. Take a git snapshot before and after the run, reduced to one SHA-256 string that is never printed: `--no-optional-locks` with `status --porcelain=v1 -z --untracked-files=all`, `rev-parse HEAD`, `symbolic-ref -q HEAD`, `for-each-ref`, `worktree list --porcelain`, `stash list`, and the hash of the git directory's `index` file bytes. The script runs only read-only git commands: no command that changes the work tree, index, refs or `.git`, and the script text (comments included) must not contain such verbs.
4. Run `dotnet <VdiffDll> --repo ... --base ... --head ... --out ...` with the optional flags, timing only that call with a stopwatch.
5. Compute: `repo_unchanged` yes, no or unknown (snapshot failure); `outputs_present` yes when `base.model.json`, `head.model.json`, `diff.json`, `summary.mmd` and `report.html` all exist under `-Out`; `wall_clock` bucket by elapsed seconds (under 60: `under-1-min`; under 300: `1-to-5-min`; under 1200: `5-to-20-min`; else `over-20-min`); `mermaid_syntax` ok, fail or skipped by running `node tools/mermaid-check/check.mjs` on `summary.mmd` with its output discarded (exit 0 ok, exit 3 or missing node or missing installed packages or `-SkipMermaid` skipped, anything else fail). The Mermaid field is informational and never changes `result`.
6. `result` is pass only when vdiff exited 0, `repo_unchanged` is yes, `outputs_present` is yes and elapsed is under 300 s; otherwise fail with the first applicable `reason` of `bad-arguments`, `out-not-outside`, `tool-failed`, `repo-changed`, `outputs-missing`, `over-budget`, else `none` on pass. This is a single run against the R26 budget, not a P90.
7. Print exactly six lines in this order: `result: pass|fail`, `reason: <value>`, `wall_clock: <bucket>`, `repo_unchanged: <value>`, `outputs_present: <value>`, `mermaid_syntax: <value>`. Exit 0 on pass, 1 otherwise. For failures before the run, `wall_clock` is `under-1-min`, `repo_unchanged` is `unknown`, `outputs_present` is `no` and `mermaid_syntax` is `skipped`.
Add a `ProjectReference` to `Vdiff.Cli` in `Vdiff.Tests.csproj` so `vdiff.dll` lands in the test output folder. `TraceRunScriptTests` (synthetic repositories only, D-09) start the script as a child process (`pwsh` required; `powershell.exe` as well when on Windows) with `-NoProfile -File`, passing `-VdiffDll` explicitly and `-SkipMermaid`, and assert: (a) a clean run, and a run with a dirty working tree and neither commit checked out, give exit 0 and exactly the six lines with result pass, repo_unchanged yes, outputs_present yes and wall_clock under-1-min; (b) `-Out` inside the repository, `-Out` inside this repository root, a non-hex `-Base`, an unknown but valid-looking commit id, and a missing `-Repo` each give exit 1, `result: fail` and the expected reason from the fixed list; (c) in every case stdout matches the six-line grammar exactly and contains none of: the repository path, the output path, the full or 7-character prefix of either commit id, the user name, the machine name. Also run `-Blank` and `-Include` once to confirm pass-through.
