<objective>
Close verification gap 1: a changed global-scope C++ type whose name is a Mermaid class-diagram keyword makes the whole `summary.mmd` unparseable. Prefix every emitted class id so no id can equal a keyword, and prove it with the real syntax check, a unit theory over the six known keywords and a lint that requires the prefix.

Purpose: roadmap criterion 3 and requirement TRC-02 need a Mermaid summary that parses. One struct named `link` in a pull request currently blanks the diagram for that whole pull request, which defeats the project's core value. The gap was reproduced end to end in `01-VERIFICATION.md` (check exit 1, parse error at the class line) and cannot be caught by the present tests: the syntax test only uses `shop::Cell` and `Gen<n>`, and the lint accepts any identifier.

Output: `ClassId` in `src/Vdiff.Core/Output/MermaidWriter.cs` builds `C_` plus the sanitised fqn; the tests that pinned the old bare form follow the new form; new tests and a tightened lint make the failure reproducible and permanent.

Decision on the prefix over a deny-list (recorded here, not left to the executor): the keyword set belongs to the pinned Mermaid version and may grow, so a deny-list would need re-checking at every upgrade. A prefix on every id is total. The review's measured keyword list is link, note, click, callback, href and cssClass; the tests use exactly those six as the known cases and prove the prefix, not the list.

Evidence the prefix is enough, gathered during planning: the expected post-fix diagram (six prefixed classes with the keyword still in the label, one inheritance edge from the prefixed `link` class to a prefixed derived class, the three `classDef` lines) was run through `tools/mermaid-check/check.mjs` and exited 0, while the same diagram with the bare `link` id exited 1 with a parse error at the class line.

Scope boundary: only the id form changes (D-08 format otherwise stays: classDiagram, classDef per state, `:::state`, trailing member tags). Findings IN-02 (edge direction for added versus removed bases) and the other review items are outside this plan.
